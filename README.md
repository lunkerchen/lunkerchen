## Selected projects

### Agent infrastructure & skills

- [labangram-agent](https://github.com/lunkerchen/labangram-agent) — Public agent rules and MCP discovery metadata for Labangram.
- [skills](https://github.com/lunkerchen/skills) — Production AI agent skill suites for SEO/GEO, adoption, content, design, engineering, and operations.
- [li-chiada-perspective](https://github.com/lunkerchen/li-chiada-perspective) ⭐ 3 — A perspective skill combining Minerva 78 Thinking Habits with decision intelligence for Hermes Agent.
- [loop-engineering-skill](https://github.com/lunkerchen/loop-engineering-skill) ⭐ 5 — A framework for designing autonomous agent feedback cycles instead of hand-prompting every step.

### AI tools & developer utilities

- [chatgpt-web-gen](https://github.com/lunkerchen/chatgpt-web-gen) ⭐ 9 — Single-file CLI for generating images through ChatGPT Web with CloakBrowser; no API key required.
- [iphone-home-screen-organizer](https://github.com/lunkerchen/iphone-home-screen-organizer) ⭐ 4 — AI-powered iPhone home screen organizer for scanning, categorizing, compacting, and auditing layouts.
- [MultiTavilyKey](https://github.com/lunkerchen/MultiTavilyKey) ⭐ 1 — Zero-dependency Tavily proxy with automatic API-key rotation for MCP clients and REST calls.

### Taiwan data & public-interest tools

- [geolook-tw](https://github.com/lunkerchen/geolook-tw) · [geolook.cc](https://geolook.cc) — End-to-end GEO implementation covering status analysis, diagnosis, strategy, tickets, execution, and verification.
- [taiwan-cases-archive](https://github.com/lunkerchen/taiwan-cases-archive) — Archive of major Taiwan social cases from 1980–2026.
- [er-map](https://github.com/lunkerchen/er-map) — Real-time congestion map for Taiwan's intensive-care-capable emergency responsibility hospitals, using NHI open data.

### Open research & reading access

- [hyread-mcp](https://github.com/lunkerchen/hyread-mcp) — Local MCP server for searching Taiwan public-library HyRead e-book collections and book availability.
