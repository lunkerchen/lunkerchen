- [labangram-agent](https://github.com/lunkerchen/labangram-agent) — Public agent rules and MCP discovery metadata for Labangram services.

### AI tools and developer utilities

- [chatgpt-web-gen](https://github.com/lunkerchen/chatgpt-web-gen) ⭐ 9 — Single-file CLI for generating images through ChatGPT Web with CloakBrowser; no API key required.
